2 — Algorithm Logic Flow

How the main loop and BFS function work together.

Start: Initialize islands=0, visit=set(), get rows & cols
Main Loop: Scan every cell (r, c) in the grid
Is grid[r][c] == "1" AND (r,c) not in visit?
YES → New island found
islands += 1
Call bfs(r, c)
BFS: Seed queue with (r,c)
Mark (r,c) visited
While queue not empty?
Pop cell → check 4 neighbors
Add valid neighbors to queue
Mark them visited
Queue empty → BFS starves
Return to main loop
NO → Skip
Move to next cell (r, c)
Key insight: BFS doesn't "break" when it hits water. It starves — no valid neighbors get added to the queue, so the queue empties and the while loop naturally exits.

4 — Complete Implementation

Clean Python3 solution with the BFS approach. Lines highlight as you step through above.

from collections import deque def numIslands(grid: list[list[str]]) -> int: if not grid: return 0 rows, cols = len(grid), len(grid[0]) visit = set() islands = 0 def bfs(r, c): q = deque() visit.add((r, c)) # mark start visited q.append((r, c)) # seed the queue while q: # runs until queue starves row, col = q.popleft() directions = [[1,0],[-1,0],[0,1],[0,-1]] for dr, dc in directions: nr, nc = row + dr, col + dc if (nr in range(rows) and nc in range(cols) and grid[nr][nc] == "1" and (nr, nc) not in visit): q.append((nr, nc)) visit.add((nr, nc)) for r in range(rows): # main scan loop for c in range(cols): if grid[r][c] == "1" and (r, c) not in visit: islands += 1 bfs(r, c) return islands

Time: O(m × n)

Every cell visited at most once by the scan + at most once by BFS. Two passes over the same data = still O(m×n).

Space: O(m × n)

Visited set can hold all cells. Queue worst case (all 1s) also holds m×n. Both scale with grid size.
