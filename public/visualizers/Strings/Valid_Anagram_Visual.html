LeetCode #242 — Frequency Counter Visual Walkthrough

Hash Map / Frequency Count Easy Strings

1 — What's the problem?

Return True if t is an anagram of s — same characters, same counts, just rearranged.

The pattern: Build a frequency count dict from s (add), then subtract using t. If all counts are zero, it's an anagram. Quick exit first: if lengths differ, return False immediately.
Key Python tool: count.get(c, 0) returns the value for key c if it exists, otherwise returns 0. Avoids KeyError on first encounter of a character.

3 — Complete implementation

def isAnagram(self, s: str, t: str) -> bool: if len(s) != len(t): # different lengths = can't be anagram return False count = {} for c in s: # build frequency count count[c] = count.get(c, 0) + 1 for c in t: # subtract if c not in count: # char in t not in s at all return False count[c] -= 1 return all(v == 0 for v in count.values()) # all zeros?

One-liner alternative: return Counter(s) == Counter(t) using from collections import Counter

Time: O(n)

Two passes through the strings. Dict operations are O(1) average.

Space: O(n)

Dict stores up to 26 entries (lowercase English letters). Could argue O(1) since alphabet is fixed size.

Pattern connection: The frequency counter pattern appears in Group Anagrams (sort or count as key), Find All Anagrams in a String (sliding window + frequency), and Longest Repeating Character Replacement (track max frequency in window). This is the building block.
