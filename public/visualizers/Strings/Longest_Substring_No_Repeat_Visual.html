Longest Substring Without Repeating Characters

LeetCode #3 — Sliding Window Visual Walkthrough

Sliding Window + Hash Set Medium Strings

1 — What's the problem?

Find the length of the longest substring with no repeating characters.

Sliding window pattern: Two pointers (L and R) define a "window." R expands right every step. When a duplicate enters the window, L shrinks right until the duplicate is gone. Both pointers only move right — the window slides like a caterpillar.

The caterpillar analogy

R is the front of the caterpillar — always stretching forward. L is the back — it only moves when the body (window) contains something invalid. The caterpillar never moves backward.

Why O(n)? Even though there's a while loop inside a for loop, each character gets added to the set once and removed at most once. Total operations = 2n at most = O(n).

3 — Complete implementation

def lengthOfLongestSubstring(self, s: str) -> int: charSet = set() # characters in current window l = 0 # left pointer res = 0 # best window size seen for r in range(len(s)): # R expands right every step while s[r] in charSet: # duplicate? shrink from left charSet.remove(s[l]) l += 1 charSet.add(s[r]) # add new char to window res = max(res, r - l + 1) # update best return res

Time: O(n)

Each character is added and removed from the set at most once. 2n operations max.

Space: O(min(n, m))

Set holds at most min(string length, alphabet size) characters. For lowercase English, that's O(26) = O(1).

Pattern connection: Sliding window appears in Longest Repeating Character Replacement, Find All Anagrams in a String, and Minimum Window Substring — all on your Blind 75 list. The expand-right / shrink-left mechanic is the same; what changes is the condition that triggers shrinking.
