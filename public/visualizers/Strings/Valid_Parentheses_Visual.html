Valid Parentheses

LeetCode #20 — Stack Visual Walkthrough

Stack Easy Strings

1 — What's the problem?

Given a string of brackets (){}[], return True if every opener has its matching closer in the correct (nested) order.

Why a stack? The most recently opened bracket must close first. That's LIFO — last in, first out. When you see {[, the [ needs to close before the {. A stack naturally enforces this ordering.
Three failure cases: (1) closer doesn't match the top of stack, (2) closer arrives but stack is empty (nothing to match), (3) loop ends with items still on stack (unclosed openers).

3 — Complete implementation

def isValid(self, s: str) -> bool: stack = [] closeToOpen = {")": "(", "]": "[", "}": "{"} for c in s: if c in closeToOpen: # it's a closer if stack and stack[-1] == closeToOpen[c]: stack.pop() # matched! remove opener else: return False # mismatch or empty stack else: # it's an opener stack.append(c) # push onto stack return not stack # empty = valid, items left = invalid

Time: O(n)

Single pass through the string. Each character is pushed/popped at most once.

Space: O(n)

Stack holds up to n/2 openers in the worst case (e.g. "((((").

Pattern connection: Stacks appear in many problems beyond parentheses: Evaluate Reverse Polish Notation, Daily Temperatures (monotonic stack), Min Stack, and decoding problems. The core idea is always the same — LIFO ordering enforces a "most recent first" processing rule.
