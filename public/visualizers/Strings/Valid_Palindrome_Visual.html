Two Pointers Easy Strings

1 — What's the problem?

Return True if the string is a palindrome after converting to lowercase and removing all non-alphanumeric characters.

Same two-pointer converge as Container With Most Water and Two Sum II — pointers at both ends, move inward. The twist: skip non-alphanumeric characters and compare case-insensitively.
Python tools: .isalnum() checks if a character is alphanumeric. .lower() converts to lowercase. If interviewers ban built-ins, use ord() ranges: A-Z (65-90), a-z (97-122), 0-9 (48-57).

def isPalindrome(self, s: str) -> bool: L, R = 0, len(s) - 1 while L < R: while L < R and not s[L].isalnum(): # skip non-alnum L L += 1 while L < R and not s[R].isalnum(): # skip non-alnum R R -= 1 if s[L].lower() != s[R].lower(): # case-insensitive compare return False L, R = L + 1, R - 1 return True

Uses Python's .isalnum() and .lower(). Clean, concise — use this on LeetCode.

def isPalindrome(self, s: str) -> bool: L, R = 0, len(s) - 1 while L < R: while L < R and not self.alphaNum(s[L]): L += 1 while L < R and not self.alphaNum(s[R]): R -= 1 if s[L].lower() != s[R].lower(): return False L, R = L + 1, R - 1 return True def alphaNum(self, c): # custom isalnum using ord() return (ord('A') <= ord(c) <= ord('Z') or ord('a') <= ord(c) <= ord('z') or ord('0') <= ord(c) <= ord('9'))

Replaces .isalnum() with manual ASCII range checks. Use this if the interviewer says "no built-in string methods." The alphaNum function checks three ranges: uppercase A-Z (65-90), lowercase a-z (97-122), digits 0-9 (48-57). Note: alphaNum is a class method here — call with self.alphaNum().

Time: O(n)

Each character visited at most once by L or R.

Space: O(1)

Two pointers. No extra string or array created.
