Container With Most Water

LeetCode #11 — Two Pointers Visual Walkthrough

Two Pointers Medium Arrays

1 — What's the Problem?

Given an array height where each value represents the height of a vertical line, find two lines that form a container holding the most water.

Water held = min(height[L], height[R]) × (R - L). The shorter line is the bottleneck — water overflows over the short side.

Why not brute force? Checking every pair is O(n²). Two pointers starting from both ends gives us O(n) — we eliminate pairs that can't possibly be better without ever computing them.

2 — Why Move the Shorter Pointer?

Start with pointers at both ends (maximum width). To find a bigger area, you need more height.

✗

Move the Taller Pointer

Height is still capped by the short side. Width shrinks. Area can only get worse. Guaranteed loss.

✓

Move the Shorter Pointer

You might find a taller line. If the height gain beats the width loss, area improves. Only path to improvement.

The rule: Always move the shorter pointer inward. If they're equal, move either — both sides are equally bottlenecked.

4 — Complete Implementation

def maxArea(self, height: List[int]) -> int: L = 0 R = len(height) - 1 max_area = 0 while L < R: h = min(height[L], height[R]) w = R - L area = h * w max_area = max(area, max_area) if height[L] > height[R]: # right is bottleneck R -= 1 # move right inward else: # left is bottleneck (or equal) L += 1 # move left inward return max_area

Time: O(n)

Each iteration moves one pointer inward. At most n-1 iterations before they meet.

Space: O(1)

Two pointers and a few variables. No extra arrays.

Pattern connection: Two Pointers from both ends also appears in 3Sum (sort + converge), Valid Palindrome (compare from ends), and Trapping Rain Water (harder variant of this problem). The "move the weaker side" logic is specific to this problem, but the convergence structure is reusable.
