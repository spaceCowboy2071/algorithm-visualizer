1 — What's the Problem?

Given an integer array nums, return an array where each element answer[i] is the product of all elements except nums[i].

Constraint: O(n) time, no division allowed.

2 — The Key Insight: Prefix × Suffix

For any position i, the answer is everything before it multiplied by everything after it.

1

prefix = 1×2 = 2 skip self suffix = 4

The trick for O(1) extra space: Don't build separate prefix and suffix arrays. Store prefix products directly in the output array (pass 1, left to right), then multiply in the suffix products using a single running variable (pass 2, right to left).

Two-Pass Algorithm

Pass 1 → Left to right: build running prefix. At each i, store the prefix in res[i], then update prefix by multiplying nums[i].

Pass 2 ← Right to left: build running postfix. At each i, multiply res[i] by the postfix, then update postfix by multiplying nums[i].

Both running variables start at 1 (the multiplicative identity).

4 — Complete Implementation

def productExceptSelf(self, nums: List[int]) -> List[int]: res = [1] * len(nums) prefix = 1 # multiplicative identity for i in range(len(nums)): # → left to right res[i] = prefix # store prefix BEFORE this element prefix *= nums[i] # update running prefix postfix = 1 for i in range(len(nums) - 1, -1, -1): # ← right to left res[i] *= postfix # multiply in postfix postfix *= nums[i] # update running postfix return res

Time: O(n)

Two passes through the array. Each pass is O(n). Total: O(2n) = O(n).

Space: O(1) extra

Output array doesn't count per the problem. Only extra space is the two running variables (prefix, postfix).

Edge cases handled automatically: Zeros in the array work fine (no division). Negatives work fine (just multiplication). Single-element edge doesn't apply since constraints say n ≥ 2.
