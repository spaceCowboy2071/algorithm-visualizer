2 — 3Sum = Outer Loop + Two Sum II

Sort the array. For each element nums[i], run Two Sum II on everything to the right, looking for pairs that sum to -nums[i].

Sort nums
For each i: fix nums[i], target = -nums[i]
L = i+1, R = end → Two Sum II on the rest

Duplicate Skipping (Two Places)

Outer loop: If nums[i] == nums[i-1], skip. All triplets starting with that value were already found.
Inner loop: After finding a valid triplet, advance L past duplicates: while nums[L] == nums[L-1] and L < R: L += 1. Prevents the same pair from matching again.

4 — Complete Implementation

def threeSum(self, nums: list[list[int]]) -> list[list[int]]: result = [] nums.sort() for i, a in enumerate(nums): if i > 0 and a == nums[i - 1]: # skip duplicate i continue L = i + 1 R = len(nums) - 1 while L < R: threeSum = a + nums[L] + nums[R] if threeSum < 0: L += 1 elif threeSum > 0: R -= 1 else: result.append([a, nums[L], nums[R]]) L += 1 while nums[L] == nums[L-1] and L < R: # skip dup L L += 1 return result

Time: O(n²)

Sort is O(n log n). Outer loop O(n) × inner two-pointer O(n) = O(n²). Total dominated by O(n²).

Space: O(1)

Sorting is in-place. Two pointers and a few variables. Output array doesn't count.

Pattern chain: Two Sum (hash map) → Two Sum II (two pointers on sorted array) → 3Sum (fix one + Two Sum II). Each builds directly on the previous. This same decomposition extends to 4Sum (fix two + Two Sum II).
