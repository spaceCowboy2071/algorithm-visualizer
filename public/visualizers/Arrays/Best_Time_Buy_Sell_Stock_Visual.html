Best Time to Buy and Sell Stock

LeetCode #121 — Single Pass Min-Tracker Visual Walkthrough

Greedy / Simplified Kadane's Easy Arrays

1 — What's the problem?

Given stock prices over time, find the maximum profit from one buy and one sell. You must buy before you sell. If no profit is possible, return 0.

The question at every position: "If I sold today, and I bought at the cheapest price I've seen so far, what's my profit?"

Two running variables: min_price — the best buy point seen so far. max_profit — the best profit seen so far. At each price: update the min if this price is lower, then check if selling here beats the current best profit.
Python loop tip: Use for price in prices to iterate values directly. Do NOT use for i in prices then prices[i] — that treats values as indices and crashes with IndexError.

3 — Complete implementation

def maxProfit(self, prices: List[int]) -> int: min_price = prices[0] max_profit = 0 for price in prices: # iterate VALUES, not indices if price < min_price: min_price = price # new lowest buy point max_profit = max(max_profit, price - min_price) return max_profit

Time: O(n)

Single pass through the array.

Space: O(1)

Two variables: min_price and max_profit.

Pattern connection: This is a simplified Kadane's algorithm. In Maximum Subarray, you decide "extend or restart" based on whether the running sum is negative. Here, you decide "update min" based on whether the current price is a new low. Both scan left to right tracking a running state and a global best.
