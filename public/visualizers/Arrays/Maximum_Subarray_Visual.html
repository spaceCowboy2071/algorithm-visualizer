Kadane's Algorithm / DP Medium Arrays

1 — What's the Problem?

Find the contiguous subarray with the largest sum. You can't skip elements — it must be a consecutive slice.

2 — The Decision at Every Step

Scan left to right, maintaining a running sum (cur_sum). At each element, ask:

Is my running sum helping or hurting?
If cur_sum is negative → carrying it forward makes the next element smaller. Reset to 0. Starting fresh is always better than dragging a negative sum along.
cur_sum ≥ 0
Extend → cur_sum += nums[i]
Keep building the subarray
cur_sum < 0
Reset → cur_sum = 0
Ditch the baggage, start fresh

After adding nums[i], check if cur_sum beats max_sub. Update if so.

Edge case — all negatives: Initialize max_sub = nums[0], not 0. That way the least-negative element becomes the answer. [-3, -5, -1, -8] → returns -1.

4 — Complete Implementation

def maxSubArray(self, nums: List[int]) -> int: cur_sum = 0 max_sub = nums[0] # NOT 0 — handles all-negatives for n in nums: if cur_sum < 0: # negative sum = dead weight cur_sum = 0 # reset — start fresh cur_sum += n # extend subarray max_sub = max(max_sub, cur_sum) # track best return max_sub

Time: O(n)

Single pass through the array. Every element examined exactly once.

Space: O(1)

Two variables: cur_sum and max_sub. No extra arrays.

Pattern connection: This "scan + decide (keep or reset)" logic is the same core idea behind House Robber, Maximum Product Subarray, and other DP problems. The running sum here is a 1D DP state — you're just not storing the full DP table because you only ever need the previous value.
