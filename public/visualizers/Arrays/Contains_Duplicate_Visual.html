1 — What's the Problem?

Given an array nums, return True if any value appears at least twice. Return False if every element is distinct.

Core idea: Scan through the array. For each element, check if it's already in a set. If yes → duplicate found, return True. If no → add it and move on. If you finish the loop without finding one, return False.
Python gotcha: {} creates an empty dict, not a set. Use set() for an empty set. Sets use .add(), dicts use .append() — mixing them up causes AttributeError.

3 — Complete Implementation

def containsDuplicate(self, nums: List[int]) -> bool: seen = set() # NOT {} — that's a dict for n in nums: if n in seen: # check BEFORE adding return True seen.add(n) # .add() for sets, not .append() return False

One-liner alternative: return len(nums) != len(set(nums))

Time: O(n)

Single pass. Set lookup is O(1) average.

Space: O(n)

Set stores up to n elements in the no-duplicate worst case.

Pattern connection: The "check set membership before adding" pattern is the simplest form of the hash-based lookup you used in Two Sum (check map before storing). Same idea, simpler problem.
