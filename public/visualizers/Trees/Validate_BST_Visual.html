Validate Binary Search Tree

LeetCode #98 — DFS with Tightening Bounds

DFS (min/max bounds) Medium Trees

1 — What's the problem?

Determine if a binary tree is a valid BST — every left descendant less than the node, every right descendant greater.

The trap: You can't just check immediate children. A node might satisfy its parent but violate a grandparent's constraint. You need bounds that tighten as you go deeper.
The rule: Going left → current value becomes the new ceiling. Going right → current value becomes the new floor. Start with (-inf, inf).

3 — Complete implementation

def isValidBST(self, root): def valid(node, low, high): if not node: # empty = valid return True if not (node.val > low and node.val < high): return False # out of bounds return (valid(node.left, low, node.val) and # left: ceiling tightens valid(node.right, node.val, high)) # right: floor tightens return valid(root, float('-inf'), float('inf'))

Time: O(n)

Visit every node once. Short-circuits on first violation.

Space: O(h)

Call stack depth = tree height.

Pattern connection: The "pass constraints down" pattern appears in many tree problems. Lowest Common Ancestor passes a target to find. Serialize/Deserialize passes bounds to reconstruct. The key insight: parent information flows DOWN through parameters, child information flows UP through return values.
