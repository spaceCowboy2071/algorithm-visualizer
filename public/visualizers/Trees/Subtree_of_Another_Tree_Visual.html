DFS + isSameTree Easy Trees

1 — What's the problem?

Return True if subRoot is an exact subtree of root — matching structure and values.

Two layers: isSubtree is the detective searching room by room (walks root with or). isSameTree opens each door and checks if everything matches (verifies with and).
Reuses Same Tree: You wrote isSameTree already — it's unchanged here. isSubtree just calls it at every node in root.

3 — Complete implementation

def isSubtree(self, root, subRoot): # SEARCH if not subRoot: # empty subtree = always True return True if not root: # ran out of tree return False if self.isSameTree(root, subRoot): # check THIS node return True return (self.isSubtree(root.left, subRoot) or # search left self.isSubtree(root.right, subRoot)) # search right def isSameTree(self, p, q): # VERIFY if not p and not q: return True # both None if not p or not q: return False # one None if p.val != q.val: return False # values differ return (self.isSameTree(p.left, q.left) and self.isSameTree(p.right, q.right))

Time: O(n × m)

For each of n nodes in root, isSameTree may check up to m nodes in subRoot.

Space: O(h)

Call stack depth = height of root tree.

Pattern connection: This "search + verify" two-layer approach appears whenever you need to find a pattern within a larger structure. The key insight: isSubtree uses or (find it ANYWHERE), isSameTree uses and (ALL must match).
