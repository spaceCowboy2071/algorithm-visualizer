Kth Smallest Element in BST

LeetCode #230 — Inorder Traversal

Inorder Traversal (stack) Medium Trees

1 — What's the problem?

Find the kth smallest value in a BST.

Key insight: Inorder traversal of a BST visits nodes in sorted order (left → process → right). So the kth node you pop is the kth smallest.
Iterative stack beats recursive: The stack approach stops after exactly k pops — O(h+k) time. The recursive approach builds the full sorted list — O(n) time. For k=1 on a huge tree, that's a big difference.

3 — Complete implementation

Iterative (optimal)
Recursive (simple)
def kthSmallest(self, root, k): stack = [] cur = root while stack or cur: # while there's work to do while cur: # go as far left as possible stack.append(cur) cur = cur.left cur = stack.pop() # next smallest k -= 1 if k == 0: # found kth! return cur.val cur = cur.right # try right subtree

O(h+k) time — stops after k pops. O(h) space for the stack.

def kthSmallest(self, root, k): sorted_list = self.inorder(root) return sorted_list[k - 1] def inorder(self, node): if not node: return [] return self.inorder(node.left) + [node.val] + self.inorder(node.right)

O(n) time — builds full sorted list. O(n) space. Simpler but slower. An interviewer will ask "can you stop early?"

Iterative: O(h + k) time

Go left O(h), pop k times. Stops early.

Space: O(h)

Stack depth = tree height.

Pattern connection: Inorder traversal is the foundation for BST Iterator, Validate BST (alternative to bounds — check if inorder is sorted), and Convert BST to Sorted Linked List. The iterative stack pattern is also used in preorder and postorder iterative traversals.
