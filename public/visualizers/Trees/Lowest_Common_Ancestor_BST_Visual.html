Lowest Common Ancestor of BST

LeetCode #235 — Find the Split Point

BST Property (split point) Medium Trees

1 — What's the problem?

Find the deepest node that has both p and q as descendants in a BST.

The BST shortcut: Because values are sorted, you just walk one path. If both p and q are less than cur → go left. Both greater → go right. Otherwise they split (or one equals cur) → that's the LCA. No need to visit both subtrees.
O(h) not O(n): You only walk one path from root to the answer. This is faster than the generic binary tree LCA which must explore both subtrees.

3 — Complete implementation

def lowestCommonAncestor(self, root, p, q): cur = root while cur: if p.val > cur.val and q.val > cur.val: cur = cur.right # both greater → go right elif p.val < cur.val and q.val < cur.val: cur = cur.left # both less → go left else: return cur # split (or match) → LCA!

Time: O(h)

Walk one path from root to LCA. O(log n) balanced, O(n) skewed.

Space: O(1)

Iterative — just one pointer variable.

Pattern connection: This BST-walk-one-path technique also applies to Search in BST, Insert into BST, and Delete from BST. The "exploit sorted property to avoid exploring both subtrees" is the fundamental advantage of a BST over a generic binary tree.
