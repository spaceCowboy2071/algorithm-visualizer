Invert Binary Tree

LeetCode #226 — Swap Children at Every Node

DFS (pre-order swap) Easy Trees

1 — What's the problem?

Mirror the tree — swap every node's left and right children, all the way down.

Pre-order this time: Unlike Max Depth (post-order), here you swap FIRST, then recurse. The work happens on the way DOWN, not back up. Either order works for this problem, but pre-order is more intuitive — "fix myself, then fix my kids."
Python trick: root.left, root.right = root.right, root.left — tuple swap, no temp variable needed.

3 — Complete implementation

def invertTree(self, root): if not root: return None root.left, root.right = root.right, root.left # swap self.invertTree(root.left) # recurse left (was right) self.invertTree(root.right) # recurse right (was left) return root

Time: O(n)

Visit and swap every node once.

Space: O(h)

Call stack depth = tree height.

Pattern connection: Same recursive skeleton as Max Depth and Same Tree. Only the "work" changes: Max Depth computes max, Same Tree compares, Invert swaps. Subtree of Another Tree (next problem) adds isSameTree at every node.
