Level Order Traversal

LeetCode #102 — BFS Level-by-Level

BFS (deque) Medium Trees

1 — What's the problem?

Return tree values grouped by level: [[3], [9, 20], [15, 7]].

Same BFS you wrote for Max Depth — deque + for i in range(len(q)). Instead of counting levels, collect values into a list per level.
The key trick: for i in range(len(q)) captures the queue size BEFORE popping. This processes exactly one level per while-loop iteration, because children added during the for loop aren't processed until the next round.

3 — Complete implementation

def levelOrder(self, root): if not root: # base case! return [] result = [] q = deque([root]) while q: level = [] # new list for this level for i in range(len(q)): # process entire level node = q.popleft() level.append(node.val) # collect value if node.left: q.append(node.left) if node.right: q.append(node.right) result.append(level) # add level to result return result

Time: O(n)

Every node visited exactly once.

Space: O(n)

Queue holds up to n/2 nodes (widest level). Result holds all n values.

Pattern connection: This BFS level-by-level template is the foundation for Binary Tree Zigzag Level Order, Binary Tree Right Side View, and Minimum Depth of Binary Tree. The for i in range(len(q)) trick is also how you did BFS for Number of Islands — same queue mechanic, different data structure.
