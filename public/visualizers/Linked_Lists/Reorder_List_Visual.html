Reorder List

LeetCode #143 — Find Middle + Reverse + Merge

Composition (3 patterns) Medium Linked Lists

1 — What's the problem?

Reorder L0→L1→L2→...→Ln to L0→Ln→L1→Ln-1→L2→... — interleave from both ends.

No new patterns — this is composition. Three steps, each one you already know: (1) Find middle with slow/fast, (2) Reverse second half, (3) Merge two halves alternating.

def reorderList(self, head): # Step 1: Find middle slow, fast = head, head.next while fast and fast.next: slow = slow.next fast = fast.next.next # Step 2: Split + reverse second half second = slow.next prev = slow.next = None # split AND init prev while second: tmp = second.next second.next = prev prev = second second = tmp second = prev # Step 3: Merge alternating first = head while second: tmp1, tmp2 = first.next, second.next first.next = second second.next = tmp1 first, second = tmp1, tmp2

Time: O(n)

Three O(n) passes: find middle, reverse, merge.

Space: O(1)

All operations in-place. Only pointer variables.

Linked Lists complete (5/6): This problem ties together every LL technique: slow/fast pointers (Detect Cycle), pointer reversal (Reverse Linked List), and merge wiring (Merge Two Sorted Lists). The only remaining LL problem is Merge K Sorted Lists (Hard) which needs the Heap pattern.
