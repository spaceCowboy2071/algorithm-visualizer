Merge Two Sorted Lists

LeetCode #21 — Dummy Node + Compare & Wire

Two Pointers (merge) Easy Linked Lists

1 — What's the problem?

Merge two sorted linked lists into one sorted list by splicing nodes together.

Dummy node trick: Create a fake head node. Build the merged list off of it. Return dummy.next at the end. This avoids special-casing which node becomes the head.
The pattern: While both lists have nodes, compare their heads. Wire cur.next to the smaller one, advance that list's pointer, advance cur. When one list runs out, attach the entire remainder of the other.

2 — Step through it

Watch cur wire to the smaller value at each step. When one list empties, the remainder attaches in one shot.

3 — Complete implementation

def mergeTwoLists(self, list1, list2): d = ListNode() # dummy node (fake head) cur = d # cur builds the merged list while list1 and list2: # while both have nodes if list1.val < list2.val: # L1 is smaller cur.next = list1 # wire cur to L1 list1 = list1.next # advance L1 else: # L2 is smaller (or equal) cur.next = list2 # wire cur to L2 list2 = list2.next # advance L2 cur = cur.next # advance cur cur.next = list1 if list1 else list2 # attach remainder return d.next # skip dummy, return real head

Time: O(n + m)

Each node from both lists is visited exactly once.

Space: O(1)

Only rewiring existing nodes. Dummy node is the only new allocation.

Pattern connection: The dummy node trick and merge pattern reappears in Merge K Sorted Lists (use a min heap to pick from K lists instead of 2), Sort List (merge sort on linked list), and Reorder List (merge two halves). The "compare heads, wire smaller, advance" logic is the core of merge sort's merge step.
