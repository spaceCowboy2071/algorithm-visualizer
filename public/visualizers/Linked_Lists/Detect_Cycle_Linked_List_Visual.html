Detect Cycle in a Linked List

LeetCode #141 — Floyd's Tortoise & Hare

Floyd's Cycle Detection Easy Linked Lists

1 — What's the problem?

Return True if a linked list has a cycle (some node's .next points back to a previous node). Return False if the list ends with None.

Floyd's Tortoise & Hare: Two pointers start at head. Slow moves 1 step, fast moves 2 steps. If there's a cycle, fast will lap slow and they'll meet. If there's no cycle, fast hits None. Think: two runners on a track — the faster one always catches up.
Why while fast and fast.next? Fast moves 2 steps, so we check both fast (not None) and fast.next (next hop exists). If either is None, we know there's no cycle — we'd have hit the end.

3 — Complete implementation

def hasCycle(self, head): slow, fast = head, head # both start at head while fast and fast.next: # fast can take 2 steps? slow = slow.next # tortoise: 1 step fast = fast.next.next # hare: 2 steps if slow == fast: # they met → cycle! return True return False # fast hit None → no cycle

Time: O(n)

Fast pointer traverses at most 2n steps before meeting slow or hitting None.

Space: O(1)

Just two pointers. No hash set needed.

Pattern connection: Floyd's algorithm extends to Find the Duplicate Number (LeetCode #287) and Linked List Cycle II (find where the cycle starts, not just if one exists). The slow/fast pointer technique also appears in Find Middle of Linked List — slow ends at the midpoint when fast reaches the end.
