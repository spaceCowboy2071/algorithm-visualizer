Remove Nth Node From End

LeetCode #19 — Two Pointer Gap Technique

Two Pointers (gap) Medium Linked Lists

1 — What's the problem?

Remove the nth node from the end of a linked list in one pass.

The gap technique: Advance right pointer n steps ahead. Now there's a gap of n between left and right. Walk both forward together. When right hits None, left is right before the node to remove.
Dummy node again: left starts at a dummy node before head. This handles the edge case of removing the head itself (when n equals the list length).

3 — Complete implementation

def removeNthFromEnd(self, head, n): dummy = ListNode(0, head) # dummy before head left = dummy # left starts at dummy right = head # right starts at head while n > 0 and right: # create the gap of n right = right.next n -= 1 while right: # walk both, maintain gap left = left.next right = right.next left.next = left.next.next # skip the target node return dummy.next # skip dummy, return head

Time: O(n)

One pass through the list (right traverses the full length).

Space: O(1)

Two pointers and a dummy node.

Pattern connection: The gap technique appears in Find Middle of Linked List (gap = slow moves 1, fast moves 2 — when fast hits end, slow is at middle). The dummy node trick is the same as Merge Two Sorted Lists. Reorder List combines both: find middle, reverse second half, merge.
